# CVP-Lite: CVP Impack급 맞춤 박스 제작기, 수작업 빌드 설계서

> 물건을 재고, 그 크기에 맞는 골판지 박스 전개도를 접이식 골판지(fanfold)에서 바로 잘라 접는 장비를
> 공방이나 차고에서 직접 만들 수 있게 정리한 설계입니다.
> 대상 장비는 Packsize가 판매하는 **CVP Impack**(Sparck Technologies 개발, 전 Quadient/Neopost)입니다.

---

## 0. 먼저 알아야 할 것

**원본 장비 사양** (공개 자료 기준. packsize.com과 sparcktechnologies.com은 이 작업 환경에서 접속이
막혀 있어서 검색 결과에 나온 수치를 썼습니다. 정확한 값은 원문으로 확인하세요.)

| 항목 | CVP Impack |
|---|---|
| 처리량 | 시간당 최대 500박스, 7초에 1박스 |
| 인원 | 작업자 2명 |
| 공정 | 3D 스캔 → 재단·괘선 → 바닥 박스 접기 + 핫멜트 → 뚜껑 성형·부착 → 계량 → 라벨 |
| 박스 크기 | 최소 180×240×100 mm, 최대 615×536×400 mm |
| 원자재 | 접이식(Z-fold) 골판지 600 / 800 / 1000 mm 폭, 피더 1~3대. C골 단골판지와 BC골 이중골판지를 바꿔 씀 |
| 설치 면적 | 약 17.8 m × 8.5 m, 높이 2.5 m (피더 3.3 m) |

**현실적인 목표.** 시간당 500박스는 길이 18 m짜리 완전 자동 라인에서 나오는 숫자입니다. 그중
접기·뚜껑·라벨 부착을 자동화한 부분이 비용과 난이도 대부분을 차지합니다. 혼자 손으로 만들면 핵심
기능(측정 → 맞춤 전개도 자동 재단·괘선 → 접기 → 계량·라벨)은 똑같이 구현할 수 있습니다. 하지만
처리량은 단계별로 올려야 합니다.

| | 원본 | **1단계 (이 문서)** | 2단계 | 3단계 |
|---|---|---|---|---|
| 측정 | 3D 스캐너 | 뎁스 카메라 + 로드셀 | 같음 | 같음 |
| 재단·괘선 | 자동 | **자동 (평판 CNC)** | 자동 | 평판 재단기 4대 + 펠트 벨트 베드 ([phase3](phase3/README.md)) |
| 접기·접착 | 자동 | 수작업 + 접기 지그 + 핫멜트 건 | **자동 성형대** ([phase2](phase2/README.md)) | 자동 |
| 계량·라벨 | 자동 | 저울 + 라벨 프린터, 수동 부착 | 프린트 앤 어플라이 | 자동 |
| 처리량 | 500/h | **60~120/h** (작업자 1~2명) | 110~230/h (재단기 2대면 210~240/h) | 이론 약 490/h, 실제 약 370~420/h |
| 크기 | 약 18×8.5 m | **약 2.2×1.6 m** | 약 6×1.6 m | 약 12×9 m |
| 예산 | 비공개 (산업용 라인) | **약 750~900만 원** | +약 1,700만 원 | +약 2억 원 (소프트웨어 포함 총 약 2.3억) |

투자 관점에서 보면, 효과는 대부분 **재단을 맞춤으로 하는 것**에서 나옵니다. 골판지를 30% 이상
덜 쓰고, 완충재가 필요 없고, 부피 기준 운임이 줄어듭니다. 처리량은 나중에 자동화로 사면 됩니다.
1단계로 실제 주문 데이터에서 박스당 원가 절감을 먼저 확인하고, 그다음에 2단계에 돈을 쓰세요.

## 1. 시스템 구성

```
 [작업대: 측정]         [재단기: 평판 CNC]                 [접기 작업대]       [계량·라벨]
 주문 바코드 스캔  →  fanfold 공급 → 피드롤러 → 베드  →  아이템을 바닥면에 →  저울 위에 올림 →
 뎁스카메라로 LxWxH     4-툴 헤드가 괘선·재단            올리고 벽 접기        라벨 출력·부착
 로드셀로 무게          (약 20~40초/장)                  귀를 핫멜트로 고정    → 출고 컨베이어
                                                        뚜껑+턱 닫기, 테이프
        └──────── Raspberry Pi 5 (측정 · 전개도 계산 · G-code · 라벨) ────────┘
                              │ USB 시리얼
                        FluidNC 컨트롤러 → 스테퍼 드라이버 / 솔레노이드 밸브
```

재단기가 다음 전개도를 자르는 동안 작업자는 앞 박스를 접습니다. 사이클 타임은
max(재단 시간, 접기 시간)이 됩니다.

## 2. 박스 형식과 전개도 계산

원본은 바닥 박스와 별도 뚜껑의 2피스 구조입니다(아래 특허 US 11,034,118, US 11,530,058 참고).
DIY 버전은 **원피스 랩어라운드 메일러**(FEFCO 0427 계열 공개 표준 형식)를 씁니다. 장점은 세 가지입니다.

- 전개도 한 장이라 재단기가 한 번만 돌면 됩니다.
- 테이프 없이 귀 4개에 핫멜트만 쏘면 됩니다.
- 별도 뚜껑 방식을 다룬 특허 청구항과 구조가 다릅니다(7장 참고).

### 2.1 치수 공식

입력: 아이템 L×W×H(mm), 여유 c(기본 5 mm), 골판지 두께 t(B골 3, C골 4, BC골 7 mm)

```
내부 치수  iL = L + 2c,  iW = W + 2c,  iH = H + c
벽 높이    h  = iH

[폭 방향 Y, fanfold을 가로지름]  측벽 h | 바닥 a + t | 측벽 h      → Ytot = a + t + 2h
[이송 방향 X]                    앞벽 h | 바닥 b + t | 뒷벽 h + t | 뚜껑 b + 2t | 턱 k

  (a, b) = (iL, iW) 또는 (iW, iL): Ytot이 fanfold 폭에 들어가면서 Xtot이 짧은 쪽
  k(턱)  = clamp(0.6h, 20, 60), 단 h − 5 이하
  귀 폭 e = min(h, (b + t)/2 − 2)     앞뒤 귀가 측벽 안쪽에서 겹치지 않게
  턱 폭  = 바닥 폭 − 2·2t              앞벽 안쪽으로 미끄러져 들어가게
```

fanfold는 600 → 800 → 1000 mm 순서로 처음 들어가는 폭을 고릅니다. 기준 모서리 쪽(y = 0)은
원단 가장자리를 그대로 써서 재단 한 번을 아낍니다.

### 2.2 선 목록 (전개도 좌표)

| 종류 | 위치 | 의미 |
|---|---|---|
| 괘선 Y방향 | x = 앞벽 끝, 바닥 끝, 뒷벽 끝 | 벽 접는 선 |
| 괘선 Y방향 | x = 뚜껑 끝 | 턱 접는 선 |
| 괘선 X방향 | y = h, y = h + a + t (x 0 → 뒷벽 끝) | 측벽 경첩, 귀 경첩 |
| 재단 Y방향 | x = 앞벽 끝, 바닥 끝, 뒷벽 끝 (양 옆 측벽 영역만) | 귀/측벽 분리 슬릿 |
| 재단 X방향 | y = h − e, y = h + a + t + e | 귀 바깥 폐기물 |
| 재단 X방향 | 뚜껑·턱 양 옆 | 뚜껑 옆 폐기물 분리 |
| 재단 X방향 | y = Ytot | fanfold 폭이 남을 때 트림 |
| 재단 Y방향 | x = Xtot, 전체 폭 | 분리 재단 (항상 마지막) |

`boxgen.py`가 이 계산을 하고 G-code와 1:1 SVG 칼선도까지 만듭니다.

```bash
python3 boxgen.py 300 200 120              # 아이템 300×200×120 mm
# → 내부 310×210×125, fanfold 600, 전개도 746×564 mm, 수율 94%, 재단 약 36초
python3 boxgen.py 300 200 120 --board BC --out out/order123
```

> **기계 없이 먼저 해 보기 (0단계):** SVG를 1:1로 출력하거나 치수만 보고 손으로 그려서 칼과 괘선 도구로
> 박스 20~30개를 직접 만들어 보세요. 여유값 c와 귀 폭이 내 물건에 맞는지 기계를 만들기 전에 확인할 수 있습니다.

## 3. 재단기 (핵심 모듈) 상세 설계

### 3.1 형식 선택: 평판 XY 갠트리 + 피드롤러

원본(Packsize 계열)은 롤러가 원단을 계속 밀어 넣고, 가로 헤드(crosshead)와 세로 헤드(longhead)가
지나가면서 자르는 **피드스루** 방식입니다. DIY 1단계에서는 다음 이유로 **평판 방식**을 씁니다.

- 원단을 베드에 고정한 상태에서 XY로 움직이므로 정밀도(±0.5 mm)를 내기 쉽습니다.
- 선 순서에 제약이 없고 원단을 되감을 필요가 없습니다.
- DIY CNC 부품(알루미늄 프로파일, 리니어 레일, 벨트, FluidNC)을 그대로 씁니다.

**핵심 아이디어:** 전개도의 선은 모두 X축 아니면 Y축과 평행합니다. 그래서 회전축(탄젠셜 나이프) 없이
**방향이 고정된 휠 4개**(X 재단, Y 재단, X 괘선, Y 괘선)를 헤드에 달고, 공압 실린더로 필요한 것만
내리면 됩니다.

### 3.2 주요 치수

```
전체 프레임     2200(L) × 1550(W) × 900(H) mm  (작업면 높이 850)
작업 영역       X 1500 × Y 1020 mm  (전개도 최대 1500 × 1000)
최대 박스(내부) 약 500 × 400 × 300 mm (1000 fanfold, C골)
최소 박스(내부) 약 120 × 80 × 30 mm
```

```
          측면도 (fanfold는 오른쪽 아래에서 들어옴)

   ┌──────────── 갠트리 (Y빔 4080, 1.25 m) ─────────────┐
   │   [헤드: KX KY CX CY 실린더 4개]                     │
 ══╪════════ 베드 1500 (MDF 25T + PP 3T 교체용 상판) ═════╪══ 피드롤러 ◎◎  ← 클램프바
   │                                                     │        ╲
   │                    프레임 4040/4080                  │         ╲ 슬랙 구간
   └─────────────────────────────────────────────────────┘          ▒▒▒ fanfold 스택
  ← 완성 전개도는 이쪽으로 빼서 접기 작업대로                         (팔레트, 바닥)
```

### 3.3 기계 부품

| 부위 | 설계 | 비고 |
|---|---|---|
| 프레임 | 4040 알루미늄 프로파일 사각 틀 + 다리 6개, 대각 브레이스 | 수평 레벨러 발 |
| 베드 | MDF 25 mm + 상판 PP 또는 HDPE 3 mm (나사 고정, 소모품) | 휠이 상판을 긁으므로 교체용 |
| X축 (1.5 m) | 양쪽 HGR20 레일 + GT3 15 mm 벨트, NEMA23 폐루프 스테퍼 2개 (갠트리 양쪽 동기) | 양쪽 따로 홈잉해서 직각 맞춤 |
| Y축 (1.1 m) | 4080 빔 + HGR15 레일 1개, GT3 벨트, NEMA23 1개 | 300 N 하중일 때 처짐 계산값 약 0.16 mm |
| 피드 | 우레탄 코팅 롤러 Ø60×1050 2개 (구동 1 + 스프링 핀치 1), NEMA23 + 1:3 벨트 감속 = A축 | 롤러 사이 간격 = 골판지 두께 − 1 mm |
| 클램프 | 롤러 바로 앞 알루미늄 앵글 바 + Ø20 실린더 2개 | 재단 중 원단 고정 |
| 헤드 | 6 mm 알루미늄 판, 실린더 4개를 60 mm 격자로 배치 | 툴 오프셋은 `boxgen.py`의 `TOOL_OFFSET`에 측정값 입력 |
| 재단 툴 KX/KY | Ø45 로터리 블레이드 (원형 커터날), 베어링 포크, 실린더 Ø25×25 | 6 bar에서 294 N. 레귤레이터로 C골 150~250 N 맞춤 |
| 괘선 툴 CX/CY | Ø40 강철 휠, 날 끝 R1.5~2, 폭 3 mm | C골 200~300 N, BC골 350 N 이상 (Ø32 실린더) |
| 슬랙 구간 | 롤러 뒤 400 mm 정도 느슨하게 늘어지게 + 가이드 롤러 | 스택에서 원단을 당길 때 충격 흡수 |

**재단 휠 팁:** 날은 베드 PP 상판에 0.5~1 mm 박히는 깊이로 합니다. 실린더 로드 끝에 스토퍼 너트를
달아 깊이를 기계적으로 제한하세요. 압력만으로 깊이를 맞추면 골 방향에 따라 편차가 납니다.

**괘선 팁:** 괘선 휠은 베드 위에서 눌러 홈을 만듭니다. 접기 품질이 부족하면 베드의 해당 위치에 홈(카운터
그루브)을 내는 대신, 괘선을 두 번(왕복) 지나가게 G-code를 고치는 편이 간단합니다.

### 3.4 공압 회로

```
컴프레서(저소음 50 L, 8 bar) → 볼밸브 → 소프트스타트 겸 덤프밸브(비상정지 연동)
   → 필터 레귤레이터(6 bar) → 매니폴드 ─┬ 5/2 솔레노이드 24 V → KX 실린더 (스피드컨트롤러 미터아웃)
                                        ├ 5/2 → KY
                                        ├ 5/2 → CX  (별도 레귤레이터로 괘선압 따로 조정 권장)
                                        ├ 5/2 → CY
                                        └ 5/2 → 클램프 실린더 2개 (병렬)
   배기는 모두 소음기
```

### 3.5 전기·제어

| 블록 | 부품 |
|---|---|
| 모션 | FluidNC (ESP32) 6축 보드, 외부 드라이버. X1, X2(슬레이브), Y, A(피드) 사용 |
| 드라이버 | NEMA23 폐루프 하이브리드 서보 4세트 (2.0~3.0 Nm), 48 V 10 A SMPS |
| 출력 | 24 V MOSFET 모듈 5채널 → 밸브. FluidNC `M62/M63 P0~P4` (`boxgen.py` `TOOL_OUT`과 일치시킬 것) |
| 센서 | 홈 센서: 유도형 NPN 24 V 3개 (옵토 절연). 원단 끝 감지: 반사형 광센서 1개 |
| 상위 | Raspberry Pi 5 (8 GB) + 10" 터치스크린. G-code 스트리밍, 비전, 라벨 |
| 측정 | 뎁스 카메라 (RealSense D435 또는 Orbbec Gemini 2, 작업대 위 0.8 m), 로드셀 50 kg × 4 + HX711 |
| 입출력 | USB 바코드 스캐너, 4×6" 감열 라벨 프린터 (ZPL 지원 모델) |
| 안전 | 비상정지 2개(재단기·작업대) → 안전 릴레이 → 드라이버 ENABLE 차단 + 덤프밸브 차단. 헤드 주변 폴리카보네이트 가드, 베드 진입 라이트커튼(선택) |

배선 원칙: 24 V 로직과 48 V 모터 전원은 공통 GND 한 점에서만 묶고, 스테퍼 케이블은 실드선으로 하고
실드를 컨트롤러 쪽에서 접지하세요.

## 4. 측정 스테이션

1. 작업대 위에 무광 검정 판 600×500 mm와 L자 코너 펜스를 둡니다.
2. 뎁스 카메라는 수직 아래로 0.8 m 높이에 둡니다. 빈 판의 깊이맵을 기준으로 저장해 둡니다.
3. 측정할 때 (기준 깊이 − 현재 깊이) > 5 mm인 픽셀만 남기고, 노이즈 제거(morphology open) 후
   가장 큰 덩어리를 고릅니다. `cv2.minAreaRect`로 L·W를 구하고, 덩어리 안 깊이 차이의 상위
   2% 값을 H로 씁니다.
4. 여러 개 담는 주문은 물건을 붙여 놓고 한 번에 잽니다. 원본도 주문 단위로 스캔합니다.
5. 보정: 100×100×50 mm 게이지 블록으로 스케일을 맞추면 ±2~3 mm면 충분합니다(여유 c = 5 mm).
6. 비상시 대체 수단: 화면에서 치수를 직접 입력할 수 있게 해 두세요.

## 5. 작업 흐름 (1단계)

| 순서 | 작업 | 시간 |
|---|---|---|
| 1 | 주문 바코드 스캔 → 물건을 측정판에 놓기 → 측정 버튼 | 5~8초 |
| 2 | Pi가 전개도 계산 → G-code 전송 → 재단기 동작 | 20~40초 (작업자 대기 없음) |
| 3 | 앞 전개도를 접기 작업대로 → 물건을 바닥면에 놓기 → 측벽 올리기 → 앞뒤 벽 올리기 → 귀 4곳에 핫멜트 → 뚜껑 덮고 턱 넣기 → 테이프 1줄 | 25~35초 |
| 4 | 저울 위에 올리면 무게 확정 → 라벨 자동 출력 → 부착 → 출고 | 5~8초 |

- 작업자 1명: 시간당 약 60~80박스
- 작업자 2명 (측정·라벨 1명 + 접기 1명): 시간당 약 100~120박스. 재단 사이클이 병목이 되므로
  큰 박스 비율이 높으면 줄어듭니다.

**접기 지그:** 합판 바닥에 가로·세로 스토퍼를 슬라이드 레일로 달아 바닥면 크기에 맞춥니다. 화면에
표시된 숫자로 맞추면 됩니다. 측벽을 받쳐 주는 90° 앵글 블록 2개를 붙여 두면 한 손으로 접을 수 있습니다.

### 7.3 이 설계와 특허의 관계 (실무 메모, 법률 의견 아님)

1. **특허는 나라마다 따로입니다.** 위 목록은 미국·유럽 특허입니다. 한국에서 문제가 되려면 같은 패밀리의
   한국 특허(KR)가 등록되어 있어야 합니다. [KIPRIS](https://www.kipris.or.kr)에서 출원인 "Quadient",
   "Neopost", "Sparck", "Packsize"로 검색해 보세요.
2. **한국 특허법은 "업으로서" 실시하는 것만 침해로 봅니다**(특허법 제94조). 개인적·가정적 실시나
   시험·연구 목적 실시(제96조)는 대체로 침해가 아닙니다. 자기 사업장 출고 라인에 쓰는 것은 "업"에
   해당할 수 있으니, 그 단계에서는 FTO 검토를 받으세요.
3. 이 설계가 원본 계열과 **구조적으로 다른 점**:
   - 박스: 별도 뚜껑 2피스가 아닌 FEFCO 0427 계열 원피스 메일러 (표준 형식)
   - 재단기: 피드스루 crosshead/longhead가 아닌 평판 XY 갠트리 + 방향 고정 휠 4개
   - 접기: 1단계는 수작업
   원문으로 확인한 결과, US 11,148,849의 방법 청구항은 **대각선 괘선이 있는 3열 전개도**를 전제로 하고,
   US 11,034,118은 **별도 뚜껑**과 높이 분할 계산을 전제로 합니다. 이 설계의 원피스 메일러에는 둘 다 없습니다.
   US 7,647,752의 독립항은 아직 확인하지 못했습니다.
4. 2단계 성형대는 US 11,230,396의 핵심인 **길이가 늘어나는 측면 가이드가 달린 별도 경화 스테이션**을
   쓰지 않고, 뚜껑도 EP 3868673 방식(별도 뚜껑 플랩으로 정렬)이 아닌 구조로 설계했습니다.
5. 만료된 특허(1990년대 슬롯·괘선 기술 등)의 도면은 자유롭게 참고해도 됩니다.

## 8. 조립 순서 (주말 단위)

1. **주 1: 0단계 검증.** `boxgen.py`로 실제 주문 20건의 SVG를 뽑아 손으로 만들어 보고 c, 귀 폭, 턱 길이를 조정합니다.
2. **주 2~3: 프레임과 베드.** 대각선 길이 차이 1 mm 이내, 베드 평탄도 ±0.3 mm (필요하면 MDF를 갠트리로 면삭).
3. **주 4: XY 모션.** FluidNC 설정, 갠트리 양쪽 홈잉, 직각 조정. 펜 홀더로 전개도를 그려 치수 검증.
4. **주 5: 공압과 헤드.** 툴 오프셋 측정 → `TOOL_OFFSET` 입력. 시험 판재로 재단 깊이와 괘선 압력 조정.
5. **주 6: 피드와 클램프.** A축 스텝/mm 보정 (1 m 이송 오차 1 mm 이내). 슬랙 구간과 원단 끝 센서.
6. **주 7: 측정과 소프트웨어.** 뎁스 카메라 보정, Pi에서 바코드 → 측정 → `boxgen` → 스트리밍 → 라벨까지 연결.
7. **주 8: 실전 시운전.** 100박스 연속 생산하면서 불량 유형(괘선 터짐, 귀 들뜸, 치수 오차)을 기록하고 조정.

**안전 수칙:** 로터리 블레이드는 실린더가 내려가 있지 않을 때도 노출되어 있습니다. 헤드 가드를 먼저 만들고
날을 끼우세요. 공압은 비상정지 시 덤프밸브로 배기되어야 합니다. 판매하거나 외부에 납품하려면 KC/CE
기계류 인증이 따로 필요합니다.
