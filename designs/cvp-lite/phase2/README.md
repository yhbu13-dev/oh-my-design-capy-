# CVP-Lite 2단계: 자동 성형대 설계서

> 1단계 재단기가 자른 전개도를 받아서 물건을 감싸 접고, 귀를 붙이고, 뚜껑을 덮고, 턱을 붙이는 데까지
> 자동으로 하는 스테이션입니다. 작업자는 물건을 바닥면에 올려놓기만 하면 됩니다.
> 1단계 설계서(`../README.md`)를 먼저 읽고 오세요.

---

## 0. 요약

| 항목 | 값 |
|---|---|
| 하는 일 | 전개도 이송 → 핫멜트 도포 → (물건 올림) → 측벽·앞뒤벽 세우기 → 귀 접착 → 뚜껑 넘기기 → 압착 → 턱 접착 → 배출 |
| 성형 사이클 | 약 15~17초/박스 (작업자가 물건 올리는 3초 포함) |
| 라인 처리량 | 재단기 1대 (고속 개조): 시간당 약 110~230박스. 큰 박스는 재단기가 병목입니다 |
| | 재단기 2대: 시간당 약 210~240박스 (성형대가 병목) |
| 인원 | 1~2명 (물건 올리기 1명, 측정·라벨·자재 보충 1명) |
| 박스 범위 (바닥 외곽, 두께 포함) | 길이 130~520 mm, 폭 120~520 mm, 벽 높이 40~300 mm. 범위 밖은 1단계처럼 손으로 접습니다 |
| 물건 무게 | 8 kg 이하 권장 (바닥면을 가운데 벨트와 패들이 받치는 구조라서) |
| 크기 | 성형대 약 2.8 × 1.4 m, 1단계 재단기와 일렬 배치하면 전체 약 6 × 1.6 m |
| 추가 예산 | 약 1,700만 원 (재단기 고속 개조 포함) |

`boxgen.py --former --fast`를 쓰면 성형대 축 위치, 접착제 토출 타이밍, 동작 순서 G-code까지 한 번에 나옵니다.

```bash
python3 ../boxgen.py 300 200 120 --former --fast --out out/order123
# → 재단 21.0초, 성형 15.5초, 라인 171박스/시간
# → out/order123.gcode (재단기), out/order123.former.gcode (성형대), out/order123.svg
```

| 라인 배치 | 스캐너 → 재단·괘선 → 성형 → 접착 → 뚜껑 배치(흡착 그리퍼) → 라벨 인쇄·부착 | US 11,034,118 도16·17 |

## 2. 이 설계는 무엇이 다른가

| | 원본 | CVP-Lite 2단계 |
|---|---|---|
| 전개도 | 트레이 + 별도 뚜껑 2장 | **한 장** (FEFCO 0427 계열 메일러, 뚜껑이 뒷벽에 붙어 있음) |
| 귀(코너판) | 안쪽으로 접어 측판 **안쪽**에 접착 | 바깥으로 접어 측벽 **바깥**에 접착 |
| 접기 기구 | 코너 4곳의 접기 유닛 | 벽 **가운데**를 미는 패들 6개 + 귀를 쓸어 붙이는 판 4개 |
| 경화 | 별도 경화 구간 (늘어나는 가이드) | 경화 구간이 따로 없음. 같은 자리에서 귀 판이 클램프로 남아 있음 |
| 뚜껑 | 별도 뚜껑, 흡착 그리퍼로 운반 | 붙어 있는 뚜껑을 프레스 헤드의 앞날로 밀어 넘기고 위에서 누름 |
| 턱 | 없음 | 앞벽 바깥에 핫멜트로 붙임 |

귀를 바깥에 붙이면 겉모양은 조금 덜 깔끔합니다. 대신 물건과 벽 사이에 기구가 들어갈 필요가 없어서 여유값 c를
1단계와 같은 5 mm로 둘 수 있고, 코너 위치를 따라다니는 기구도 필요 없습니다.

## 3. 전체 배치

```
                         평면도 (위에서 봄, 단위 mm)          +Y (작업자 반대편)
   ← 재단기에서                                                   ↑
  ─────────────────────────────────────────────────────────────────────────────── 
   infeed │ 접착건(-860) │ 귀 판 대기(-815…-565) │  성형 구역  │ 헤드 대기 │ outfeed →
          │  ■ L         │  ▭▭▭▭▭ (위 측면빔)     │ ┌───┬───┐ │   ▣       │
  ════════╪══════════════╪══ 가운데 벨트 40 ═════╪═│═══╪═══│═╪═══════════╪══════  +X
          │  ■ 턱(+40)   │                        │ └───┴───┘ │ (+400…+1200)
          │  ■ R         │  ▭▭▭▭▭                │  ↑측패들(x=0)│
   펜스(B축) ─────        브러시 베드 (나일론 솔 25 mm, 패들·벨트 지나갈 홈 3줄)
                                                          작업자 쪽 (-Y), 라이트커튼
```

| 모듈 | 축/액추에이터 | 역할 |
|---|---|---|
| 가운데 벨트 | **A축** (스테퍼, 40 mm 타이밍벨트 + 마찰 코팅) | 전개도를 들여오고, 접착 타이밍의 기준이 되고, 완성 박스를 내보냄 |
| 펜스 | **B축** (스테퍼 + 벨트, Y방향) | 전개도 기준 모서리(y = 0)를 맞춰 바닥면 중심을 Y = 0에 둠 |
| 앞뒤 패들 캐리지 | **X축** (좌/우 나사 볼스크루 1개로 대칭 이동) | 앞뒤 괘선 위치(±바닥 길이/2)로 이동. 캐리지마다 회전 액추에이터 2개(벨트 양옆) |
| 측면 캐리지 | **Y축** (좌/우 나사 볼스크루. 아래 패들 캐리지와 위 측면빔을 모터 2개로 동기) | 측면 괘선 위치(±바닥 폭/2)로 이동. 아래에는 측패들, 위에는 귀 판과 접착건 |
| 프레스 헤드 | **C축** (X방향 리니어 모듈 1.5 m) + **Z축** (볼스크루 1 m) | 앞날로 뚜껑을 밀어 넘기고, 판으로 누르고, 앞쪽 와이퍼로 턱을 접음 |
| 접착 | 핫멜트 멜터 + 건 3개 (측면빔에 L·R, 고정 브리지에 턱용) | 전개도가 지나갈 때 귀와 턱 윗면에 비드를 쏨 |

축이 6개(X, Y, Z, A, B, C)라서 **FluidNC 보드 1장**으로 됩니다. Y의 위·아래 캐리지는 모터 2개를 같은 축에 슬레이브로 묶습니다.

## 4. 좌표계와 셋포인트 공식

성형대 좌표: **원점 = 바닥면 중심**, +X = 벨트 진행 방향 (뒷벽·뚜껑 쪽), 앞벽은 −X 쪽.
전개도는 **턱이 먼저** 들어옵니다.

```
bx = 바닥 길이(X) = along + t          by = 바닥 폭(Y) = across + t
h  = 벽 높이                           lid = 뚜껑 길이 = bx + t,  K = 턱 길이

X (앞뒤 패들)      = ± bx/2
Y (측면 캐리지)    = ± by/2
B (펜스)           = −(h + by/2)                     전개도 y = 0 모서리 위치
A_stop (벨트)      = x5 − (바닥 중심 x) − SENSOR_X      센서가 앞끝을 본 뒤 이송량
C_park (헤드 대기) = bx/2 + h + lid + K + 60          서는 뚜껑 끝보다 바깥
Z_plow             = h + 0.7·lid                     앞날이 서 있는 뚜껑의 70% 높이를 침
C_press            = −bx/2 − t − 6 + 160             와이퍼가 앞벽 바로 바깥에 오도록
Z_hold             = h + 2t
귀 폭 e            = min(h, bx/2 − 45)                가운데 측패들(|x| < 35)과 겹치지 않게
```

**접착 타이밍:** 건은 X = −860에 고정되어 있고 전개도가 지나갑니다. 전개도 위 점 x가 건 아래를 지나는 벨트 위치는
`A = GUN_X − SENSOR_X + (x5 − x)`입니다. 턱 → 뒷귀 → 앞귀 순서로 지나가고, 앞귀가 붙는 시점까지 약 4~6초,
턱이 붙는 시점까지 약 10~12초 걸립니다. **열린 시간(open time)이 12~15초 이상인 핫멜트**를 고르세요.

## 5. 동작 순서

| # | 동작 | 기구 | 시간(초) |
|---|---|---|---|
| 0 | 헤드가 대기 위치 (C_park, Z_plow), 각 축이 셋포인트로 이동 | X, Y, B, C, Z | 앞 박스 배출과 겹침 |
| 1 | 전개도 진입. 접착건이 턱·뒷귀·앞귀에 비드 토출. 바닥 중심에서 정지 | A, 건 3개 | 2.5~4 |
| 2 | 레이저 십자선을 보고 작업자가 물건을 바닥 가운데 올림. 라이트커튼이 비면 사이클 시작 | 작업자 | 3 |
| 3 | **측패들 2개 올림** → 측벽이 섬 | 회전 액추에이터 | 0.5 |
| 4 | **앞뒤 패들 4개 올림** → 앞뒤 벽이 서고, 귀는 모서리 바깥으로 날개처럼 튀어나옴. 뚜껑은 뒷패들에 기대 수직으로 섬 | 회전 액추에이터 | 0.5 |
| 5 | **귀 판 4개가 바깥에서 가운데로 쓸고 들어옴** → 귀가 측벽 바깥 면에 눌려 붙음. 판은 그 자리에 남아 클램프 역할 | 로드리스 실린더 | 0.9 |

| 8 | 뒷패들 내림 | | 0.3 |
| 9 | **헤드 하강** → 판이 뚜껑을 평평하게 누름 | Z축 | 0.5~1 |
| 10 | **턱 와이퍼 하강** → 턱이 앞벽 바깥에 접혀 붙음. 1.5초 유지 | 실린더 | 1.8 |
| 11 | 헤드 상승, 귀 판 복귀 | Z, 로드리스 | 0.8 |
| 12 | 벨트가 박스를 출고 컨베이어로 내보냄 (헤드 아래로 통과). 헤드는 대기 위치로 복귀 | A, C | 2~3 |

| 출력 | 이름 | 밸브 |
|---|---|---|
| P0 | SIDE_PADDLES | 5/2, 측패들 회전 액추에이터 2개 |
| P1 | FRONT_PADDLES | 5/2, 앞패들 2개 |
| P2 | BACK_PADDLES | 5/2, 뒷패들 2개 |
| P3 | EAR_FRONT | 5/2, 앞쪽 귀 판 로드리스 2개 |
| P4 | EAR_BACK | 5/2, 뒤쪽 귀 판 로드리스 2개 |

FluidNC 기본 출력이 모자라면 I2S 출력 확장 보드(16채널)를 붙이세요.

## 6. 기구 상세

### 6.1 브러시 베드 (작업면)
- 나일론 솔 스트립(솔 길이 25 mm)을 알루미늄 프레임에 촘촘히 박아 만든 면입니다. 전개도는 솔 위를 미끄러지고,
  패들은 솔을 헤치고 올라옵니다.
- 솔 사이에 **홈 3종류**를 둡니다.
  - 가운데 벨트 홈: |y| < 22, X 전체 길이
  - 앞뒤 패들 홈: |y| = 23~53 두 줄, X 방향
  - 측패들 홈: |x| < 35, Y 방향
- 측패들과 앞뒤 패들은 항상 이 홈 안에서만 움직입니다. 그래서 패들 위치가 박스마다 바뀌어도 솔과 부딪치지 않습니다.

### 6.2 패들 (벽 세우기)
- 패들: 알루미늄 판 4 mm, 측패들 70 × 320 mm, 앞뒤 패들 30 × 320 mm (벨트 양옆에 한 쌍).
- 구동: 랙앤피니언 **회전 액추에이터 90°** (사이즈 20~30, 0.5 MPa에서 약 2 N·m). 골판지 벽을 세우는 힘은 1 N·m 미만입니다.
- **회전축은 괘선 바로 아래**에 와야 합니다. 축 중심을 작업면에서 −(t/2)에, 괘선 X/Y와 일치하게 두고, 패들 판 윗면이 솔 끝과 같은 높이가 되게 합니다.
- 패들이 h보다 길어서 작은 박스에서는 벽 위로 튀어나옵니다. 뒷패들은 이 튀어나온 부분이 뚜껑을 수직으로 세워 줍니다.

### 6.3 귀 판 (귀 접기 + 클램프)
- UHMW-PE 10 mm 판 250 × 290 mm. 바닥은 작업면 위 12 mm에 떠 있어서 평평한 전개도가 그 아래로 지나갑니다.
- 판 뒤에 10 mm 스펀지를 대서 측벽 쪽으로 살짝 눌러 주고, 앞끝은 R10으로 둥글려 귀를 접어 넘깁니다.
- 로드리스 실린더 Ø25 × 550 mm (측면빔 1개에 앞뒤 2개). 대기할 때 판 앞끝은 X = ∓565 바깥에 있어서, 일어서는 앞뒤 벽과 귀 날개(최대 x = ∓560)와 부딪치지 않습니다.
- 끝까지 가면 앞끝이 X = ∓45에 멈추고, 판이 귀가 있을 수 있는 구간(∓295…∓45) 전체를 덮어 누릅니다.

### 6.4 프레스 헤드 (뚜껑 넘기기, 누르기, 턱)
- 위쪽 X방향 리니어 모듈(1.5 m, 벨트 구동) + Z 볼스크루 모듈(1 m). 헤드는 Y 폭 80 mm로 좁게 만들어 측면빔(최소 |y| = 60 + t)과 부딪치지 않게 합니다.
- 프레스 판 80 × 300 mm (스펀지 5 mm). −X 쪽 앞날은 R15 둥근 바(뚜껑을 밀 때 긁히지 않게)입니다.
- 턱 와이퍼: 헤드 중심에서 −160 mm, Ø20 × 100 실린더 끝에 폭 40 mm 우레탄 롤러를 달고, 롤러가 앞벽 쪽으로 3° 기울어 내려가게 합니다.

### 6.5 접착
- **소형 핫멜트 멜터 (3~5 L) + 가열 호스 3개 + 전기/공압 건 3개.** 측면 건 2개는 측면빔에 달려 Y를 따라가고, 턱 건은 Y = +40 고정입니다.
- 비드 길이: 귀는 벽 높이의 가운데 50%, 턱은 턱 길이의 가운데 40%.
- 수작업 대안: 처음에는 건 대신 **양면 테이프 디스펜서**를 작업자가 붙이는 방식으로 시작해도 기구 검증에는 충분합니다.

### 6.6 안전
- 작업자 쪽(−Y)에 **타입 4 라이트커튼**을 둡니다. 커튼이 가려지면 FluidNC safety door 입력으로 피드홀드를 걸고, 공압 덤프밸브를 차단합니다.
- 사이클 시작은 커튼이 빈 상태에서 발판 스위치나 버튼으로만 걸립니다 (G-code의 `M0` 이후).
- 헤드가 내려오는 구역은 위에서 손이 들어갈 수 없게 폴리카보네이트 덮개를 씌웁니다.
- 핫멜트는 180 °C 안팎입니다. 건 주변에 손 가드와 경고 표지를 다세요.

## 7. 재단기 고속 개조 (`--fast`)

성형대가 15~17초인데 1단계 재단기는 300×200×120 박스에 36초가 걸립니다. 재단기가 병목이 되지 않게 고칩니다.

| 항목 | 1단계 | 2단계 |
|---|---|---|
| 재단·괘선 속도 | 300 mm/s | **600 mm/s** |
| 이동 속도 | 600 mm/s | **1000 mm/s** |
| 실린더 동작 | 0.15 s | **0.10 s** (밸브를 헤드 가까이로 옮기고 배관을 짧게) |
| 드라이버 | 폐루프 스테퍼 | 폐루프 스테퍼 유지, 48 V → 60~70 V, GT3 15 mm → **20 mm** 벨트 |
| 300×200×120 재단 시간 | 35.7 s | **21.0 s** |

큰 박스가 많으면 재단기를 **2대**로 늘리고 성형대 앞에서 합류시키세요. 원본이 피더를 1~3대 쓰는 것과 같은 이유입니다.

## 10. 조립·시운전 순서

1. **베드와 벨트**: 브러시 베드 홈 위치를 도면대로 맞추고, 벨트 위에서 빈 전개도를 왕복시켜 직진성을 확인합니다(3 m 이송 중 Y 편차 2 mm 이내).
2. **X·Y 캐리지**: 좌/우 나사 볼스크루의 대칭 오차를 확인합니다(양쪽 차이 0.5 mm 이내). Y의 위·아래 캐리지 동기도 확인합니다.
3. **패들 단독 시험**: 물건 없이 전개도만 놓고 벽 세우기를 100회 반복하면서 괘선과 회전축 정렬을 조정합니다.
4. **귀 판**: 접착 없이 귀 접기만 반복해서 판 높이와 스펀지 압력을 조정합니다.
5. **헤드**: Z_plow 비율(기본 0.7)을 바꿔 가며 뚜껑이 앞으로 넘어가는지 확인합니다.
6. **접착**: 비드 위치와 열린 시간을 맞추고, 붙은 박스를 손으로 뜯어 섬유가 찢어지는지(접착 성공) 확인합니다.
7. **연속 시험**: 크기 10종을 섞어 200박스를 연속으로 만들면서 실패 유형을 기록합니다.

## 11. 남은 위험

- **뚜껑 넘기기**는 판지 괘선의 복원력에 따라 결과가 달라집니다. 넘어가지 않으면 Z_plow 비율을 올리거나, 헤드 앞날에 작은 회전 플랩을 추가하세요.
- 바닥면을 가운데 벨트와 패들만 받치므로 **무거운 물건(8 kg 이상)**은 바닥이 처질 수 있습니다. 볼 트랜스퍼를 솔 사이에 섞어 보강할 수 있습니다.
- 바깥 귀 방식은 박스 옆면에 귀 자국이 보입니다. 브랜드 박스가 중요하면 3단계에서 안쪽 귀 방식을 검토하되, 그때는 코너 접기 유닛 관련 특허를 다시 확인해야 합니다.
